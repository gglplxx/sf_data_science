# Project 0. Guess the number

## Оглавление

### Project Description
Угадать загаданное компьютером число за минимальное число попыток.

### Какой кейс решаем?
Нужно написать программу, которая угадывает число за минимальное число раз.

**Условия соревнования:**
- Компьютер загадывает число от 0 до 100, и нам его нужно угадать. Под "угадать" подразумевается "написать программу, 
которая угадывает число".
- Алгоритм учитывает информацию о том, больше ли случайное число или меньше нужного нам.

**Метрика качества**
Результаты оцениваются по среднему количеству попыток при 1000 повторений.

**Что практикуем**
Учимся писать хороший код на Python
